# 《寶島風情畫》遊戲共用設定與系統規範 (Game Design & Common Specifications)

本文件定義《寶島風情畫》全系列的通用遊戲架構、顯示規範、物件行為邏輯、主角性能與關卡共通格式，供後續關卡（如 `level2.md` 及後續關卡）實作與擴充時共同遵循。

---

## 一、 遊戲基本架構

- **遊戲類型**：2D 橫向捲軸射擊遊戲（Horizontal Scrolling Shoot 'em up / Shmup）
- **美術風格**：90 年代街機像素風格 + 臺灣在地特色元素（空拍照視差背景、臺灣特色主題魔王等）
- **核心架構**：純 HTML5 Canvas + Web Audio API（完全無外部函式庫與資產相依，即開即玩）

## 二、 畫面與視圖規格 (Display & Viewport)

| 項目 | 規格值 | 說明 |
| :--- | :--- | :--- |
| **內部原生解析度** | 800 × 480 像素 | 經典 5:3 街機比例，外層等比自適應縮放至任何螢幕寬度 |
| **瓦片網格單元 (Tile Size)** | 60 × 60 像素 | 地圖每一字元對應 60 × 60 px 區域 |
| **關卡標準高度** | 8 列（Rows 0 ~ 7） | 8 × 60 = 480 px，垂直方向剛好對應視窗高度 |
| **關卡標準寬度** | 99 欄（Cols 0 ~ 98） | 99 × 60 = 5940 px 總長度，平均推進時間約 90~120 秒 |
| **自動捲軸速度 (Scroll Speed)** | 50 px / 秒 | 平滑平移攝影機，推動玩家前進 |
| **BOSS 鎖定區域** | 第 80 ~ 85 欄左右 | 抵達終點前捲軸鎖定固定，觸發警報演出後進入頭目戰 |

## 三、 地圖字元定義 (Map Legend & Entity Symbols)

所有關卡地圖檔案（如 `docs/level1.md`, `docs/level2.md`）一律遵循下列符號標準：

| 符號 | 名稱 | 說明與行為邏輯 |
| :---: | :--- | :--- |
| `e` | **固體地形 / 岩層** | 阻擋戰機與子彈。戰機擦撞扣護盾並彈開；子彈命中消散產生火花。 |
| `->` | **主角戰機起始點** | 主角飛機初始登場之網格座標（預設常位於第 4 列第 1 欄）。 |
| `x` | **巡航敵機** | 進入視野時先進行上下正弦波擺動並發射 1 發慢速子彈，隨後向前高速俯衝。 |
| `\|` | **天花板下墜陷阱** | 懸掛於頂部，主角水平接近時劇烈震動，隨即受重力加速度下砸。**落地碎裂後不再重生**。 |
| `s` | **背刺突襲敵** | 初始隱形，主角行經該觸發欄位時左側邊緣亮起警訊，隨後從後方高速殺出並發射子彈。 |
| `塔` | **要塞砲塔** | 安裝於天花板或地面基座，砲管具備全角度向主角轉向鎖定能力，週期發射重型砲彈。 |
| `boss` | **關卡巨大首領** | 位於關卡末段方框中（`┌──────┐`），具備多階段彈幕型態與大血條。 |

## 四、 主角戰機系統規格 (Player Ship)

### 1. 基礎數值
- **機體尺寸**：寬 46 px、高 24 px
- **判定核心（Hitbox）**：寬 26 px、高 14 px（微小核心判定，方便擦彈與精確鑽隙）
- **移動速度**：260 px/秒（8 方向移動，斜向具備向量正規化）
- **初始殘機（Lives）**：3 架（全數耗盡即 Game Over）
- **護盾能量（Shield）**：3 格（受傷扣 1 格，歸零時扣 1 殘機並重置為 3 格）
- **無敵保護（Invulnerability）**：
  - 受傷受挫：1.2 秒（機體閃爍）
  - 扣命重生：2.5 秒（機體閃爍）

### 2. 武器系統（Weapon Level 1 ~ 4）
- **LV1（標準）**：單發高速電漿光束（射速 650 px/s，冷卻 0.14s，按住連發）
- **LV2（雙重）**：雙線平行雷射砲
- **LV3（三叉戟）**：三向扇形散射雷射（涵蓋正前方與上下斜角）
- **LV4（重火力）**：重型高能雙雷射 + 自動尋標追蹤微型飛彈（Homing Micro-Missiles）

### 3. 全螢幕炸彈（BOMB / EMP）
- **初始數量**：2 顆（上限 4 顆）
- **效果**：
  - 消除全畫面所有敵方彈幕並轉化為獎勵得分
  - 對全畫面所有可視敵人造成 5 點重擊傷害；對 BOSS 造成 15 點重擊傷害
  - 觸發全螢幕白光震波與強烈震動效果

### 4. 戰場掉落補給物（Drop Items）
敵人遭消滅時有機率掉落上下漂浮的能量膠囊：
- `P`（Power Up）：升級主武器等級（最高 LV4）
- `S`（Speed Up）：提升戰機飛行速度（上限 360 px/s）
- `B`（Bomb +1）：補充 1 顆全螢幕炸彈
- `H`（Heal Shield）：修復 1 格護盾能量

## 五、 敵人與障礙物行為邏輯 (Enemy Logic)

### 1. 巡航敵機 (`x`)
- **生命值**：2 HP / **得分**：100 分
- **行為循環**：
  1. **等待（WAITING）**：攝影機水平距離接近至 850 px 以內時啟動。
  2. **正弦盤旋（BOBBING）**：上下正弦波擺動 1.6 秒（振幅 ±36 px），微向左漂移。
  3. **射擊**：擺動至 1.0 秒時，瞄準主角所在方向發射 1 發慢速橘紅電漿彈（速度 150 px/s）。
  4. **向前突進（ADVANCING）**：擺動結束後以 185 px/s 速度向前（向左）直線衝刺。

### 2. 背刺突襲敵 (`s`)
- **生命值**：3 HP / **得分**：250 分
- **行為循環**：
  1. **未觸發（UNSPAWNED）**：主角飛機橫向坐標到達或超過其觸發欄位（`c * 60 - 250`）時啟動。
  2. **警報（ALERT）**：螢幕左緣在對應高度閃爍「◀ REAR ALERT」警訊 0.6 秒。
  3. **背刺衝刺（RUSHING）**：自畫面左緣（`cameraX - 40`）高速向右（向前）切入衝刺（速度 220 px/s），並向主角發射定向慢速子彈。

### 3. 天花板掉落陷阱 (`|`)
- **生命值**：不可破壞（碰撞即觸發）
- **行為循環**：
  1. **懸掛（HANGING）**：靜止掛於天花板處。
  2. **感知震動（SHAKING）**：主角水平接近在 160 px 範圍內時，陷阱高頻顫抖 0.35 秒並發出預警聲。
  3. **重力下砸（FALLING）**：以重力加速度（g = 650 px/s²）垂直下墜砸向地面。
  4. **撞地碎裂（DESTROYED）**：碰撞固體地形 `e` 或觸及底邊界立即大爆炸碎裂，**掉落後永久消失不重生**。

### 4. 要塞砲塔 (`塔`)
- **生命值**：6 HP / **得分**：350 分
- **安裝機制**：第 0~3 列判定為天花板懸吊砲塔；第 4~7 列判定為地面堡壘砲塔。
- **追蹤射擊**：砲管依據主角當前座標平滑旋轉瞄準，每隔 2.4 秒向瞄準方位射出 1 發重加農砲彈。

## 六、 物理與碰撞規則 (Physics & Collision)

1. **主角與地形碰撞**：
   - 採用 AABB 最小穿透維度（Overlap Vector）推回機制，主角擦撞壁面時沿外沿平滑滑動，不穿牆、不卡死。
   - 每次擦撞地形扣除 1 格護盾並產生金屬刮擦火花。
   - 若被捲軸強制推擠（左側螢幕邊界 `cameraX` 將機體硬推至固體地形），判定為夾殺直接受傷並彈出。
2. **子彈與地形碰撞**：
   - 所有玩家或敵方實體子彈在命中 `e` 地形時立刻被吸收消除，並爆出碎屑火花。
3. **主角邊界約束**：
   - 主角戰機活動空間恆被鎖定在當前螢幕視窗範圍之內：`[cameraX + 10, cameraX + 800 - w]`。

## 七、 音效與音樂架構 (Audio Synthesizer)

遊戲內建 Web Audio API 即時聲音合成器，無須下載任何外部音效或音訊檔：

- **射擊音效（playLaser）**：鋸齒波 880Hz → 160Hz 快速頻率滑降。
- **敵彈音效（playEnemyLaser）**：三角波 420Hz → 140Hz 柔和波導。
- **爆炸音效（playExplosion）**：白噪聲生成緩衝區（White Noise Buffer）經低通濾波器包絡衰減。
- **落石預警與撞擊（playTrapRumble / playTrapCrash）**：低頻震顫與重度爆破碎裂。
- **警報鈴（playWarning）**：800Hz / 500Hz 雙音交替防空警報。
- **吃道具音效（playPowerup）**：正弦波 C5-E5-G5-C6 快速上行琶音。
- **炸彈震撼音（playBomb）**：重低音震撼與巨型爆破混音。
- **8-bit FM Chiptune 背景音樂**：
  - 111 BPM 快速節奏、D 小調。
  - 三角波 Bass 聲道 + 方波主旋律/琶音聲道 + 噪聲脈衝打擊樂聲道。

## 八、 操作按鍵配置 (Controls)

| 鍵位 | 功能 |
| :--- | :--- |
| **方向鍵** 或 **W / A / S / D** | 八方向移動主角戰機 |
| **Space** / **J** / **Z** | 發射武器（支援長按自動連發） |
| **K** / **X** / **B** | 施放全螢幕炸彈（消彈 + 全畫面敵機傷害） |
| **P** | 暫停 / 繼續作戰 |
| **M** | 靜音 / 開啟音效 |
| **R** | 任務失敗或突破成功時重新開始 |
| **觸控介面** | 行動裝置自動啟用虛擬 D-pad 十字鍵與發射/炸彈專用大按鍵 |

## 十、 關卡資料編譯器 (Level Data Compiler)

專案提供自動化 Python 解析器腳本 [`scripts/parse_levels.py`](file:///Users/zonble/Work/baodao/scripts/parse_levels.py)，可直接讀取 Markdown 地圖規格文件並編譯為輕量緊湊的 JavaScript 資料模組：

### 執行方式
```bash
python3 scripts/parse_levels.py
```

### 功能特色
1. **直接解析 Markdown**：自動循序掃描 `docs/level*.md`，從純文字 ASCII 網格中解析出所有地圖元件（`e`、`->`、`x`、`s`、`塔`、`|` 與首領方框）。
2. **自動全形寬度計算**：精確支援中文字元（如 `塔` 佔 2 欄寬度）之座標對齊。
3. **緊湊格式化（Compact Packing）**：採用二元座標陣列 `[r, c]` 結合解包函式 `unpack()`，將原本數千行的冗長 JSON 物件壓縮至約 170 行（約 10 KB），體積縮小 80%，兼顧極佳的可讀性與執行效能。
4. **即時同步**：後續新增關卡（如 `docs/level4.md`）後，僅需執行該腳本即可全自動更新 [`js/levelData.js`](file:///Users/zonble/Work/baodao/js/levelData.js)。
